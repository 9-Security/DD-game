# 《七日之藥，深淵之願》角色設定集

**Character Design Bible — Chapter 1 / Version 1.0**

## 設計原則

- 美術風格：寫實黑暗奇幻（Realistic Dark Fantasy），結合中古世紀服飾、低調魔法元素與實用冒險裝備。
- 角色設定以故事第一章及既定主角資料為基準；年齡、身高、外貌與未命名 NPC 形象是 v1.0 美術補充設定，後續應納入統一版本管制。
- 遊戲立繪、3D 模型、動作、表情、裝備變體及 AI 生圖都應沿用固定識別特徵。
- 角色能力需有世界觀內合理限制，避免破壞七日任務或核心謎題。

## 一、主要角色

### 1. 艾洛恩‧維斯塔（Eron Vesta）

| 欄位 | 設定 |
|---|---|
| 性別 | 男性 |
| 年齡 | 24 歲（v1.0 建議） |
| 身高 | 178 cm（v1.0 建議） |
| 職業 | 牧靈使（Spiritual Shepherd） |
| 隊伍定位 | 主角／輔助、治療、淨化、自然共鳴 |
| 核心信念 | 生命應被尊重，即使那是敵人 |

**背景與能力：** 能與動植物心靈共鳴，具有療癒與淨化能力。極少出現在戰場，此次為王國命運挺身而出。

**外觀：** 身形修長，深褐色及肩長髮，灰綠色眼睛；臉部輪廓柔和、略顯疲憊。左側頸部有淡褐色樹枝狀紋路，非一般刺青。生命共鳴時虹膜可出現細微金綠光環。

**服裝風格：** 苔綠色防風斗篷、米白色亞麻內襯、深棕皮帶與長靴。服裝使用枝葉、根系刺繡，材質以自然纖維、木材與皮革為主。腰間攜帶藥草袋、水囊、簡易療傷工具；裝備為木質牧靈杖。

**性格：** 溫和、內斂、耐心、善於觀察。傾向理解對方而非命令。常在行動前先感知周遭生命。

**人格缺陷：** 太在意每一個生命，可能因此錯失戰鬥時機。

**最大恐懼：** 自己終究必須在不同生命間作出犧牲選擇。

**角色成長命題：** 拯救一個生命若必須犧牲另一個生命，能否維持最初的信念？

**行為／演出：** 語調較低、常短暫停頓，透過觸摸植物或土地感知環境。施法以柔和光粒、呼吸、手掌接觸與生命脈動呈現，避免爆炸式視覺效果。

| 技能 | 定位 |
|---|---|
| 生命共鳴 | 感知生物情緒與環境生命反應 |
| 靈息治癒 | 回復生命值、治療傷勢 |
| 自然淨化 | 清除部分毒素與異常狀態 |
| 靈魂安撫 | 降低敵意、穩定失控召喚物 |
| 生靈連結 | 與動植物建立短暫協作關係 |

**能力限制：** 不等於復活術，也無法輕易治癒碎魂熱。

**固定視覺識別：** 灰綠眼睛、深褐長髮、頸部植物紋、自然材質服裝、木質牧靈杖。

### 2. 芙蕾雅‧雷恩（Freya Rayne）

| 欄位 | 設定 |
|---|---|
| 性別 | 女性 |
| 年齡 | 32 歲（v1.0 建議） |
| 身高 | 183 cm（v1.0 建議） |
| 職業 | 狂戰士（Berserker） |
| 隊伍定位 | 前排主力／高傷害、破防、承受攻擊 |
| 武器 | 雙手巨劍「亡父之骨」 |

**背景與能力：** 前皇家近衛軍隊長，身負血之詛咒，壽命將盡。渴望在最後的時間裡做有意義的事，視戰鬥為贖罪。

**外觀：** 高挑、健壯、肩寬且肌肉結實；黑褐色長髮束成低馬尾，琥珀色眼睛。右眉有舊傷，身上留有歷次戰鬥疤痕。左手腕及前臂以深紅繃帶遮掩詛咒；發作時深紅紋路沿左臂向肩頸擴散，瞳孔逐漸轉紅。

**服裝風格：** 磨損的暗黑鋼鐵護甲、深紅布料、皮革固定帶及舊式皇家近衛軍裝備。原軍階標誌被刻意磨除，保留殘缺輪廓。護甲可見刮痕、凹痕與修補痕跡。

**武器設計：** 「亡父之骨」為厚重黑鐵雙手巨劍，護手有骨骼分岔造型。名稱不代表必然以父親遺骨打造，此細節待劇情正式確認。

**性格：** 沉默寡言、果斷、紀律嚴明，偶爾以簡短諷刺回應里克特。

**核心信念：** 戰士必須對自己的選擇負責。

**人格缺陷：** 過度傾向用自我犧牲解決問題。

**最大恐懼：** 詛咒使她失去自我，傷害需要保護的人。

**角色成長命題：** 活著承擔責任，可能比壯烈犧牲更困難。

| 技能 | 定位 |
|---|---|
| 斷骨重擊 | 單體高破防傷害 |
| 戰場守護 | 攔截或承受隊友攻擊 |
| 血怒 | 消耗生命換取戰鬥能力 |
| 亡父之骨 | 重劍蓄力與範圍攻擊 |
| 詛咒暴走 | 高風險戰鬥狀態 |

**能力限制：** 詛咒須同時造成劇情與戰鬥代價，不應僅為傷害增益；代價與可逆性待機制定義。

**固定視覺識別：** 高挑健壯、右眉疤、黑鐵護甲、深紅封印繃帶、雙手巨劍「亡父之骨」。

### 3. 里克特‧安布羅斯（Lict Ambros）

> 命名規格：依既定角色資料，中文名「里克特‧安布羅斯」，英文寫法 **Lict Ambros**，不得自行改寫為其他拼法。

| 欄位 | 設定 |
|---|---|
| 性別 | 男性 |
| 年齡 | 29 歲（v1.0 建議） |
| 身高 | 175 cm（v1.0 建議） |
| 職業 | 符文盜賊（Rune Rogue） |
| 隊伍定位 | 探索專家／陷阱破解、機動、精準攻擊 |
| 核心信念 | 每個任務背後都有權力的交易 |

**背景與能力：** 前情報販子，轉職為冒險者。對地下結界與陷阱極敏銳，對王宮保持懷疑。

**外觀：** 精瘦靈活，灰褐色短髮，冷灰色眼睛。下巴有一道細小舊傷；儀容俐落，常觀察出入口，不輕易背對陌生人。

**服裝風格：** 炭灰、煙黑、暗棕與舊銀為主。穿深灰短外套、窄身長褲、低噪音軟底靴及露指手套。服裝磨損集中手肘、膝蓋和工具接觸處。

**配件：** 腰間懸掛多枚刻有符文的薄金屬片，搭配工具盒、皮袋、精密器具；胸口內袋用於紙條、情報及交易憑證；隨身攜帶懷錶。

**性格：** 機敏、多疑、毒舌、善於推理。經常用不完整的真相或刻意的透露時機保護自己，不會毫無理由地說謊。

**人格缺陷：** 難以相信不求回報的善意。

**最大恐懼：** 再次成為權力交易的犧牲品。

**角色成長命題：** 隊伍利益與自身利益衝突時，能否放棄最有利的自保選項？

| 技能 | 定位 |
|---|---|
| 符文解析 | 解讀古代裝置與部分封印 |
| 陷阱感知 | 偵測地下機關 |
| 符片屏障 | 短時間防禦 |
| 弱點標記 | 暴露敵人防禦弱點 |
| 干擾符印 | 中斷特定施法或機關 |

**能力限制：** 符片、工具等應有材料或次數消耗，不可無限制破解所有封印。

**固定視覺識別：** 冷灰眼、精瘦體態、符文金屬片、懷錶、精密工具、深灰短外套。

### 4. 茵芮‧朵維亞（Inry Dovya）

| 欄位 | 設定 |
|---|---|
| 性別 | 女性 |
| 年齡 | 19 歲（v1.0 建議） |
| 身高 | 160 cm（v1.0 建議） |
| 職業 | 召喚學徒（Summoner Apprentice） |
| 隊伍定位 | 遠程魔法／召喚支援、高風險輸出 |

**背景與能力：** 剛從魔法學院退學，聲稱神喻草與某種上古精靈有關，堅持加入任務以證明自身價值。具極強魔力，但控制力不穩。

**外觀：** 體型嬌小、膚色偏白，淺亞麻金長髮、髮尾略捲，藍紫色眼睛。常有研究熬夜留下的黑眼圈，手部可見施法造成的細小燙痕。高度集中魔力時瞳孔周圍出現銀色光芒。

**服裝風格：** 深海軍藍、灰白與淡銀色。穿略顯過大、不完全合身的學院制式斗篷，原徽章拆除後留有縫線，搭配短靴和大型書袋。

**配件：** 大型皮革召喚書有金屬補強書角、多張書籤與手寫註記。配置四枚召喚晶石，呼應第一章「鏡影精靈」召喚方式。

**性格：** 理性、好奇、求知慾旺盛，遇到壓力時容易衝動。理論能力強，但實戰經驗不足。

**核心信念：** 個人價值不該只由制度的認可決定。

**人格缺陷：** 害怕被看輕，經常在準備不足時急於證明自己。

**最大恐懼：** 失去控制，傷害信任自己的同伴。

**角色成長命題：** 從追求強大的力量，轉向理解力量的責任。

| 技能 | 定位 |
|---|---|
| 鏡影召喚 | 投影、偵查、映照魔法痕跡 |
| 精靈契約 | 與召喚物建立協作 |
| 魔力增幅 | 強化召喚物能力 |
| 召喚轉移 | 重新指定召喚物位置 |
| 契約失衡 | 特定條件下發生失控風險 |

**能力限制：** 失控須與魔力負荷、精神壓力和環境干涉等具體因素關聯，不宜完全隨機。

**固定視覺識別：** 淺金長髮、藍紫眼睛、略大斗篷、巨大召喚書、四枚晶石、銀色瞳孔紋路。

### 7. 鏡影精靈（Mirror Spirit）

| 欄位 | 設定 |
|---|---|
| 類型 | 契約召喚生物 |
| 首次出場 | 第一章〈黑曜石之門〉 |
| 外觀 | 無臉的人形輪廓，由浮動銀色鏡片與淡藍魔力連結構成 |
| 行動特徵 | 安靜、動作緩慢，映照視覺景象與特定魔力痕跡 |
| 異常表現 | 鏡片顯示非當前時空景象，失控時浮現大量陌生眼睛 |
| 本質 | 不以人類善惡評判，對契約者精神狀態產生反應 |

**第一章事件解釋：** 攻擊行為應視為黑曜石之門未知力量干涉召喚連結，而非精靈天生邪惡。

**召喚動畫建議：** 銀色晶片逐漸拼接成人形；異常時鏡片失序旋轉、反射未知景象，最後隨契約穩定分解為光點。

## 三、第一章其他短暫登場角色

- **王都城門守衛：** 開場背景人物；有換崗、守夜與城門值勤行為。無獨立姓名與完整人物弧線，採通用守衛 NPC 資產。
- **晨間運貨車夫與市井居民：** 開場城市生活氣氛角色；採通用平民 NPC 資產。
- **王宮神官、藥師：** 僅在病情背景中提及，未具體登場，不列為本章完整角色資產。

## 五、遊戲美術製作規格

每名正式角色至少建立：

1. **角色三視圖：** 正面、側面、背面；供 3D 建模及一致性比對。
2. **表情設定表：** 中性、喜悅、悲傷、憤怒、恐懼及角色專屬表情。
3. **服裝裝備拆解圖：** 外套、內襯、護甲、鞋履、腰帶、道具和武器。
4. **動作參考：** 待機、行走、探索、戰鬥、施法、受傷及特殊劇情動畫。
5. **AI 生圖提示詞：** 角色固定特徵、服裝版本、鏡頭視角、禁用特徵及風格控制。

## 六、設定管理與待定項目

**已確定的故事核心：** 四位主角的姓名、英文名、職業、既定背景與信念；星墜之淵、七日倒數、碎魂熱、神喻草、黑曜石之門、第一章鏡影精靈失控事件。

**本版新增美術設定：** 四人的年齡、身高、外貌細節、服裝材質、疤痕／印記位置、技能暫名與演出細節。這些應視為 v1.0 設計提案，正式量產前須凍結版本。

**尚待正式確認：** 國王與公主姓名；國家與王室紋章；「亡父之骨」名稱由來；角色過去事件細節；血咒來源與完整機制；神喻草真相；古代語言與鏡影精靈的完整契約法則。

**一致性底線：** 不因單張生圖更改固定視覺特徵；不任意添加會牴觸故事主線的復活或萬能治療；新增世界觀秘密需經劇情設定確認。
