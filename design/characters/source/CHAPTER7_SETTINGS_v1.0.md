## 3. 重要人物設定與演出

### 3.1 黎安娜公主

**原稿確立：** 17 歲、罹患碎魂熱、記憶逐步散失；其個人意志與知情同意是最後選擇不可刪去的一環。「黎安娜」原稿註明為重建創作版本的暫定名，但因後續小說持續使用，**本作品當前 Canon 沿用此名**。若未來要改名，必須全系列同步修訂。

**外觀定稿（第七章新增補足，保持先前角色集的栗棕髮、銀藍眼識別）：** 17 歲少女，栗棕色長髮，銀藍色眼睛，面色蒼白；象牙白與淡藍色寢衣，低調銀線繡紋。不要將她畫成成年 22 歲形象。患病表現重點是辨識遲疑、疲倦和眼神失焦，不能把碎魂熱誤當成皮肉腐壞。

**性格：** 對他人痛苦敏銳，不願自己成為犧牲他人的藉口；即使記憶殘缺，仍可要求解釋與參與決定。她不是「恢復記憶就自然同意一切」的被動物件。

**A：** 病症得到治療；開始遺忘犧牲的父王之面貌與姓名。  
**B：** 存活但失去大部分童年記憶，走向城牆迎接護界消失後的日出。  
**C：** 第七夜未獲及時救治而失去意識；到第八日仍未甦醒，**不可聲稱已死亡或仍必然可救**。

### 3.2 國王

**原稿既定性格：** 承擔國家責任、害怕失去護界與女兒；知道部分歷史，並非已證實知道所有細節。

**名稱限制：** 現有原稿與第七章共同主線沒有明示正式本名。**結局 A 的小說出現國王姓名被拼回並刻下的事件，但未在設定集中擅自指定新姓名；本名仍屬待核對項。** 後續創作可另行正式命名，但不得改寫已輸出的結局 A 內容。

**外觀美術（續用角色集提案，於本章定稿）：** 約 55–60 歲，髮鬢斑白，深藍與黯金色王室禮服，簡潔王冠。政治權威與父親的疲倦須能同時讀出。

**A：** 自願提供完整靈魂；同意並非自動免責，犧牲後姓名與面容逐漸自人們的記憶、紀錄中消散。  
**B：** 存活，必須面對護界熄滅、王室責任與對黎安娜失去記憶的無力。  
**C：** 存活，因未及時獲得神喻草而啟動備用儀式，繼續舊制；尚未獲赦免。

### 3.3 艾洛恩・維斯塔（Eron Vesta）

**固定角色設定：** 牧靈使，尊重所有生命，擅長共鳴、治癒與淨化；不是萬能復活者。

**第七章任務：** 解釋神喻草的限制；交出透明種子並維持黎安娜的知情權。對兩條方案均有倫理責任，不能忽略犧牲者或王國人民。

- A：見證自願犧牲成功，但明白悲劇制度沒有改變。
- B：與透明種子的共鳴配合，以神喻草重織公主**殘存**靈魂；不創造完整新靈魂。
- C：保持完整神喻草，不得擅稱其仍有能力逆轉已發生的失去意識。

### 3.4 芙蕾雅・雷恩（Freya Rayne）

**固定狀態：** 父親阿德里安的名骨片在身；「亡父之骨」劍身已裂、王室強制服從魔咒已破，但早先血咒所造成的壽命問題**未證實完全消除**。

**第七章任務：** 出示密令與父親的處決證據，拒絕再讓「服從」成為殺害無辜者的藉口。

- A：不作為自動犧牲者；國王的犧牲不得取代她學會為自己活下去的角色弧線。
- B：使用既有斷誓經歷切斷王室血誓的連結；不憑空獲得新的無限制斬界能力。
- C：仍保有選擇權，決定重返深淵。

### 3.5 里克特・安布羅斯（Lict Ambros）

**固定背景：** 符文盜賊、前情報販子，兄長凱恩列於被抹除者姓名紀錄。凱恩的名字已刻在匕首柄上。

**第七章任務：** 提供姓名證據、解讀並逆轉符文；其重點由尋求個人復仇提升為保存所有人的名字。

- A：將國王姓名刻在凱恩名字旁；**刀柄刻痕不隨正常記憶消除**。這是該分支已定稿的特性，不能反推刀具在任何情況都有普遍防遺忘能力。
- B：逆轉誓約相關符文，使群靈得以離開；不可改成單人獨力解除整個護界。
- C：持續保留凱恩姓名與證據，反對備用儀式，決意重返深淵。

### 3.6 茵芮・朵維亞（Inry Dovya）

**固定背景：** 退學召喚學徒，曾因失控事件失去導師瑟維恩的去向；第六章學會傾聽群靈名字而非強迫封閉召喚門。

**第七章任務：** 穩定召喚／引導被困靈魂；力量仍受魔力負荷與環境限制。

- A：參與見證儀式，不擅自改變選定的完整靈魂代價。
- B：以真名傾聽引導群靈離去；**不是將群靈變成個人軍隊或永久召喚寵物**。
- C：保留對已知名字的記憶，重返深淵的動機是阻止重演。

## 4. 王宮場景與環境資產

### 4.1 王宮藥室（LOC-PALACE-HEAL-001）

**敘事功能：** 七日旅程回到序章起點；當事人黎安娜在此聽見真相並決定如何被救。

**美術定稿：** 石砌王宮藥室，挑高但不奢華，窗邊留有序章銀葉草，桌面有御醫用具、燭台、神喻草容器及調查文件；材質以灰石、舊木、白色床單、深色木雕為主。不可把藥室改成全新地點而造成序章空間不連續。

**可互動證物：** 死亡名冊／抄錄、王室誓約文字、封村密令、處決紀錄、名骨片、斷誓巨劍、七葉神喻草、透明種子、凱恩刻名匕首。

**演出規範：** 公主的清醒程度可隨碎魂熱波動，但最終知情選擇時必須能理解並表達意願。種子與神喻草共鳴時，姓名光點是象徵「被記住的人」的視覺效果，不新增可任意復活的能力。

### 4.2 王城城牆（LOC-CITY-WALL-001）【僅 B】

護界熄滅之後，日出不再受到保護屏障遮擋。黎安娜立於城牆，看見第一道沒有護界的晨光。視覺以晨霧、石砌城牆、淡金色日光與遠方邊境不安為主；**不可直接描繪王國已全面毀滅**。

### 4.3 守淵村與深淵入口【僅 C】

第八日的守淵村仍有晨霧；鐘聲不合時宜地再次響起。四人晚間在星墜之淵入口重新集結。黑曜石之門、失聲之庭、血誓熔窟的既有狀態不因 C 而重置：巨獸已獲解縛、鐵甲已崩潰、芙蕾雅斷誓已完成。

## 6. 結局 A：代價之藥（END-A）

### 6.1 成立條件

在第七夜期限內抵達王宮，經過共同主線的真相與知情討論，最終採用「自願完整靈魂補缺」方案。**第七章小說已將自願者確定為國王；在此小說版本內不得改成芙蕾雅或其他人。**

### 6.2 事件與因果

1. 國王在看到死亡名冊及女兒意願後，自願提供完整靈魂。
2. 其自願必須經過明示，不得將被逼迫或含混答應當成有效條件。
3. 黎安娜可明確知悉代價並提出拒絕；在此分支中最後接受救治。
4. 神喻草引導王的完整靈魂補上黎安娜缺失的部分。
5. 黎安娜病況改善並存活；國王消失，其姓名與面孔逐漸自記憶及紀錄中褪色。
6. 里克特在原刻有凱恩名字的匕首旁刻下國王姓名；儘管眾人開始遺忘，刻痕仍留存。
7. 護界仍存，制度根本問題**未被解除**。

### 6.3 美術與情緒

燭光昏暗的王宮藥室、七葉神喻草變得透明、黎安娜清醒卻逐漸記不起父王、匕首上兩列名字。畫面避免把國王犧牲表現成王權獲得全面赦免的勝利典禮。

### 6.4 分支不可改動點

**國王死亡／消失；黎安娜獲救；護界延續；里克特保留刻名。** 無法直接轉入 B 的國王仍活著場景。

## 7. 結局 B：斷誓黎明（END-B）

### 7.1 成立條件

第七夜前抵達；四位主角先前的主線關鍵經歷已完成；黎安娜理解解誓風險，與四人共同選擇解放被囚群靈。前六章的所有角色成長在既有小說中已發生，若改編遊戲需以任務旗標判定。

### 7.2 四人角色分工

| 角色 | 依據 | 結局 B 的執行工作 |
|---|---|---|
| 里克特 | 第三章保全姓名、符文解析 | 以姓名紀錄逆轉誓約相關符文 |
| 芙蕾雅 | 第五章斷誓、父親名骨片 | 切斷王室血誓束縛 |
| 茵芮 | 第六章真名傾聽 | 引導被扣留靈魂依序離去 |
| 艾洛恩 | 第四章透明種子及牧靈淨化能力 | 以神喻草及種子共鳴重織黎安娜殘存靈魂 |

### 7.3 結果

- 墜星誓約解除，墜星之心破碎，王國護界熄滅。
- 被拘束的群靈離開原先囚禁之地。不可寫成全部人均完整復活。
- 黎安娜存活，代價是失去大部分童年記憶；**她並未恢復所有過去**。
- 國王仍存活，必須面對王室責任及護界失效後的政治局面。
- 荒潮出現在邊境，前景不安定；不預設王國立即滅亡。
- 城牆日出是正式終章畫面；核心意涵為失去舊有保護後開始承擔自由與新風險。

### 7.4 分支不可改動點

**國王存活、護界消失、黎安娜失去部分記憶、荒潮威脅開始顯現。** 不可繼承 A 的靈魂犧牲、國王被遺忘或 C 的備用儀式。

## 8. 結局 C：未竟的第八日（END-C）

### 8.1 正確分歧位置

**第六章取得神喻草已是固定歷史。** C 因歸途中未及時返回而成立，時間線與「第七夜前抵達王宮」的共同主線分離。它不是「沒有取得神喻草」，更不是共同主線選擇後無端倒退回未抵達狀態。

### 8.2 事件與結果

1. 四人在第六日取得神喻草，但返回延誤，未在第七夜前到達王宮。
2. 黎安娜於第七夜失去意識；仍未證實她死亡。
3. 國王啟動王室備用儀式，強行送入**另一個新的靈魂**以延續護界。**該被犧牲者的姓名／完整身分未被原稿確定，不自行填上熟悉角色**。
4. 四人帶著完整神喻草及證據返回，卻已錯過原本的治療窗口。
5. 到第八日，公主仍未醒來；神喻草能否改變她當前處境是未解問題。
6. 王城表面平靜，護界仍存；守淵村的鐘在不該響起的第八日再次響起。
7. 四人決定重返深淵，為的是阻止下一次犧牲，不是保證能倒轉已發生的一切。

### 8.3 分支不可改動點

**國王存活、黎安娜未醒、神喻草仍未施用、備用儀式已奪走新靈魂、舊誓約延續。** 不得寫成黎安娜在第八日自然痊癒，也不可用 A 或 B 的已完成治療狀態覆蓋此分支。

## 9. 遊戲化方案（新增定稿規格）

此節屬 RPG 互動規格，並非小說中已存在的遊戲程式。

### 9.1 任務與結局旗標

```yaml
schema_version: '1.0'
quest_id: Q07
chapter_id: CH07
flags:
  divine_herb_acquired: true
  herb_leaf_count: 7
  memory_names_preserved: true
  freya_blood_oath_broken: true
  inry_true_name_listening_completed: true
  transparent_seed_acquired: true
  arrived_before_deadline: null
  evidence_presented_to_king: false
  royal_orders_presented: false
  liana_informed_of_costs: false
  liana_consent_recorded: false
  final_choice: null
  ending_id: null
```

`ending_id` 只允許 `END_A`、`END_B`、`END_C` 之一；`final_choice` 不可在到達期限之前提前寫死。

### 9.2 分支判斷

```text
IF arrived_before_deadline == false:
    ending_id = END_C
ELSE:
    REQUIRE evidence_presented_to_king
    REQUIRE royal_orders_presented
    REQUIRE liana_informed_of_costs
    IF final_choice == voluntary_sacrifice AND liana_consent_recorded:
        REQUIRE king_explicit_voluntary_consent
        ending_id = END_A
    ELSE IF final_choice == break_oath AND liana_consent_recorded:
        REQUIRE memory_names_preserved
        REQUIRE freya_blood_oath_broken
        REQUIRE inry_true_name_listening_completed
        REQUIRE transparent_seed_acquired
        ending_id = END_B
    ELSE:
        remain_at_final_decision
```

**機制限制：** 原稿 C 是時限失敗，不可因使用者在結尾畫面選擇「沉默」就無條件判定已延誤一整晚；遊戲可另設明確逾時條件。A 的「國王主動犧牲」必須有獨立且可稽核的同意旗標，不得假設所有角色死亡都屬自願。

### 9.3 存檔分離原則

- 共同主線存檔：`chapter7_predecision`，僅供第七夜前抵達者選 A/B。
- C 的存檔：`chapter7_late_arrival`，不能從共同主線最後對話直接覆寫切入。
- 分支封存後，分別記錄 `king_alive`、`liana_awake`、`barrier_active`、`oath_active`、`herb_used`、`wild_tide_visible`，不得以單一 `ending_success` 表示全部狀態。
- 避免以「好／壞」數值標示 A/B/C。三條結局代表不同倫理代價、世界風險及敘事結果。

## 11. 後續敘事約束與未解問題

1. **沒有唯一正史結局。** 如需續作，先明確選擇 A/B/C 的起點，不可將三條平行路線融合。
2. 國王正式名字仍需確認；結局 A 的刻名行為已寫入小說，但本文不提供未經核對的具體拼字。
3. 結局 A 的犧牲沒有解決王室以靈魂維持護界的制度性問題。
4. 結局 B 中「自由」不等於「完全安全」；護界已失效、荒潮在邊境出現。
5. 結局 C 的備用犧牲者尚未具名；若續作新增姓名，必須維持「第七夜強制犧牲」的時間與因果。
6. 瑟維恩・洛德的真實生死在前六章未證實；第七章不能直接宣稱他已完全復活或被徹底消滅。
7. 凱恩・安布羅斯與阿德里安・雷恩的既定身世不因分支重設。
8. 芙蕾雅強制服從魔咒已破，但「原血咒影響壽命的殘餘問題」仍不可未經描寫就宣稱全數治癒。
9. 第三、四章被保留或解縛者的名字與記憶，應持續成為未來故事倫理主題，不只是一次性過關獎勵。
10. 結局 B 的國王存活；結局 A 的國王犧牲；結局 C 的國王仍在位並須面對備用儀式的責任。
