# 鏡影精靈（Mirror Spirit）正式定位

> 版本：v1.0　日期：2026-10-23
> 依據：第二章小說、第二章設定集（`design/characters/source/CHAPTER2_SETTINGS_v1.0.md`）、
> 以及採用的「封印守衛」定位（見第五節）。
> 狀態：採用中。若要改動，須先更新本文件與 `CHARACTER_BIBLE.md` 第 7 節。

## 一、正式定位

| 項目 | 定位 |
|---|---|
| 身分 | 黑曜石之門第一道封印的守衛 |
| 類型 | 具有限自主意識的封印靈體（Sentient Seal Guardian） |
| 陣營 | 中立，不屬於王室或冒險者 |
| 主要職責 | 執行誠實試煉 |
| 核心能力 | 映照與受試者有關的真實記憶、顯現其內心秘密、鏡像反擊 |
| 行為原則 | 依試煉規則判斷，不依善惡決定通行 |
| 是否可擊殺 | 不設計為一般可擊殺敵人 |
| 是否可召喚 | 不可作為茵芮的召喚物；不會成為永久召喚獸 |
| 是否知道誓約真相 | 尚未定案；僅掌握本封印相關資訊 |

## 二、敘事功能

1. **第二章**：考驗者而非反派。它不主動追殺四人，而是迫使他們面對過去。
   芙蕾雅攻擊銀鏡後的反擊，是試煉機制被觸發，不是精靈出於敵意。通關條件是承認，不是擊敗守衛。
2. **第三章**：不提前解釋王室誓約。死亡名冊與古代誓約仍須由里克特在咒牆迷廊中發現。
3. **後續劇情**：建立深淵封印的基本規則。封印不一定以戰鬥解除，有些要求理解、承認或選擇。
   這與第四章艾洛恩解放被囚禁靈魂的選擇，以及第七章犧牲與否的主題一致。

## 三、禁止事項（不得讓鏡影精靈具備）

- **全知**：不知道任何人完整的命運與未來。
- **改寫記憶**：只能顯現真實記憶，不能捏造或修改歷史。
- **離開封印**：活動範圍限於黑曜石之門。
- **解除血咒**：芙蕾雅的詛咒留到第五章處理。
- **揭露神喻草代價**：完整代價是第六章的揭露節點。

## 四、遊戲實作對照

| 項目 | 現況 |
|---|---|
| 承認試煉（四人承認、順序不限、不花時間） | 已實作（`ch2_confess_*`、`ch2_gate_open`） |
| 鏡像反擊（芙蕾雅攻擊鏡面） | 未實作；設計上為試煉機制，不是敵對行動 |
| 通關不以擊殺為條件 | 已符合：目前沒有擊殺分支 |
| 不作為召喚物 | 已符合：茵芮的 `mirror_summon` 是她自己的投影技能，與精靈無關 |
