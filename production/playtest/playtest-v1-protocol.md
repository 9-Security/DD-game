# 第一版真人遊玩協定

## 一、目的

確認第一版在真人遊玩下的節奏、理解度與操作流暢度。自動化測試與示範腳本已驗證流程，但無法替代以下判斷：

- 對白的長度與節奏是否可以接受（尤其是第三章名冊廊廳、第五章與第七章）。
- 玩家能否理解每一步該做什麼（按鈕文字、危險標示、確認列）。
- 隨機的序列失敗與時限，是否讓玩家感到不公平或難以理解。
- 結局 A、B、C 的分歧是否可以被玩家察覺與理解。

## 二、建置與開啟

1. 解壓 `dd-game-web-build.zip`，得到 `index.html` 與相關檔案。
2. 以本機靜態伺服器開啟（例如 `python3 -m http.server 8000`），在 Chrome 或 Edge 中瀏覽 `http://localhost:8000/index.html`。
3. 直接從序章開始，不要使用網址參數。
4. 建議以桌面瀏覽器操作；網頁版在手機上未驗證。

## 三、遊玩範圍

- 從序章開始，完整遊玩到任一結局。
- 每位測試者只需遊玩一次，但請盡量自然地玩，不要查閱攻略。
- 允許中途存檔，並記錄存檔的時機。
